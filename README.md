# UNO CLUB

三个独立页面：`/` 经典 UNO、`/flip` UNO FLIP、`/flex` UNO FLEX。彩色牌全部带游戏开发部大头照，万能牌为 Kei。

## 线下四台设备一起玩

仓库保持 **Private**。GitHub 保存源码；联机房间由现场的一台电脑运行，朋友不需要 GitHub 账号。

1. 主机安装 Node.js 22.13 或更高版本，下载仓库后在目录中执行一次 `npm ci`（这一步需要网络）。
2. 四台设备连接同一个 Wi-Fi 或手机热点。在主机运行 `npm run lan`，Windows 也可双击 `start-lan.cmd`。
3. 启动窗口会显示当前主机的局域网地址，例如 `http://192.168.2.47:3000`。四台设备打开窗口显示的地址；换网络后地址可能变化。
4. 房主选择“四台设备”，输入昵称创建房间，点击“邀请”。另外三人打开邀请链接并输入昵称入座，全部准备后由房主开局。
5. 主机保持开机、运行窗口开启。准备好依赖后，现场游玩不需要外网；图片、程序、房间数据库都在主机。

第一次启动会自动构建和创建本地数据库，重复启动不会清空牌局。停止用 `Ctrl+C`。默认端口 3000；脚本优先使用 Wi-Fi 网卡，并排除常见 VPN/虚拟网卡。多网卡可用 `UNO_HOST` 指定本机局域网 IPv4，`UNO_PORT` 指定端口。

若手机打不开，先确认使用的是局域网地址而非 `localhost`，设备没有连接隔离的访客 Wi-Fi。Windows 若弹出防火墙提示，请允许该服务访问你们使用的可信局域网；本项目不会自动关闭或修改防火墙。

## 房主切换设备模式

- 牌桌顶部的“四设备 / 单设备”由房主控制，其他设备只能查看当前模式。
- **四设备**：每位玩家使用自己的设备，只收到自己的手牌。
- **单设备**：房主设备轮流控制四名玩家，每次交接自动遮住手牌；其他已连接设备只看公共牌桌，不能出牌，也收不到手牌。
- 对局中切换保留手牌、牌堆、回合和分数，不重新洗牌。初始单设备牌局切成四设备后，另外三台设备可直接加入接管对应座位。
- 单设备是四人轮流操作，不包含 AI 对手。旧版本本机同屏存档仍可继续，新建单设备牌局统一使用本地房间服务，以支持随时切换设备。

## 使用

- 在线：输入昵称创建房间，把邀请链接给另外三位玩家。四人点准备，房主开局。房间保留24小时，同一浏览器标签页刷新后可以重连。
- 同屏：填写四个昵称；每次交接点击“我已接手”才显示当前玩家手牌。房间状态保存在运行服务的电脑上。
- 点击亮框牌出牌，万能牌选择颜色，强化定向牌另选目标。FLEX 先打开强化按钮。
- 剩两张时可提前喊 UNO，漏喊可被举报。加牌叠加、500分赛在开局时选择。
- 设置可关闭声音及震屏；系统“减少动态效果”默认关闭动画。

## 规则边界

依据 Mattel 经典 UNO、GDR44 FLIP 与 HMY99 FLEX 说明书实现，详细来源与规则在页面“游戏规则”中。

数字版约定：FLIP 每局随机生成双面配对，局内固定，非实体印刷配对复刻。FLEX 副色使用固定轮转分配。翻面后若新顶牌是万能，由下一位行动者选色。缺少可抽牌时只抽现有牌，避免无限循环。

可选叠加是房规，默认关闭。只叠同种数值加牌；不混接、不叠定向/群体/抽色。开启后数值万能加牌由系统强制合法，不再质疑。有人出完手牌时先结算最后一张罚牌，再计分。

## 本地开发

Node.js >=22.13，npm。依赖已经在当前交付目录安装。

```powershell
npm ci
npm run build
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_tiresome_punisher.sql
npm run dev -- --port 5173
```

数据库迁移只在新的本地数据库执行一次。不要在已存在的表上重复执行。开发服务默认为本机访问。

```powershell
node --experimental-strip-types tests/game.test.mjs
node tests/room.test.mjs
```

后一个测试需要本地服务已经运行。测试使用本地四会话与D1，不代表真实跨地区网络延迟测量。

## 实现

- React / Vinext / TypeScript，Cloudflare Worker + D1 房间持久化。
- 服务端权威判定，版本比较更新避免同时操作覆盖；操作标识防止重复提交。
- 每个座位有随机凭证，服务器只存SHA-256摘要，客户端仅收到自己手牌。
- 房间状态约每1.1秒同步；不使用 WebSocket，不提供AI代打。
- 游戏核心在 lib/game.ts；在线接口 app/api/room/route.ts；页面 app/ui/arcade.tsx。
- 浏览器 WebMCP 提供只读牌桌工具，尊重同屏遮挡。

## 素材

- 卡牌头像：红 / 粉色为桃井，绿 / 橙色为小绿，蓝 / 紫色为爱丽丝，黄 / 青色为柚子，所有万能牌为 Kei。覆盖数字牌和功能牌，FLIP 两面都按当前颜色对应。只改变卡面和出牌闪光，不影响规则。玩家仍使用座位编号和自定义昵称，在设置中可预览五张卡面。
- 彩蛋插画：内置 imagegen 一次生成的同人素材；public/card-easter-eggs.png。原始生成提示词保留在 public/card-art-prompt.txt，图集现仅用于卡面。
- Kei：使用内置 image_gen 生成，素材 `public/kei-portrait.png`，完整提示词 `public/kei-prompt.txt`。造型参考[官方角色介绍](https://x.com/Blue_ArchiveJP/status/2015621284898775451)，为非官方同人图。
- UNO牌面参考与下载素材：Dmitry Fomin / Wikimedia Commons / CC0 1.0，public/uno-cards-cc0.svg。
- 动态牌面为代码绘制的游戏UI；图标 Lucide（ISC）。
- UNO 与蔚蓝档案角色相关权利归各自权利人。本项目是非官方同人练习。

## GitHub 交付

仓库保存完整源码，访问权限为 Private。没有启用 GitHub Pages 或公开云部署。当前交付是可运行的同一局域网版本；GitHub 仓库链接本身不是游戏网址。房间需要服务端和数据库，纯静态 Pages 不能独立运行房间接口。

本地房间使用 [Cloudflare 本地运行时与 D1](https://developers.cloudflare.com/workers/local-development/local-data/)，不需要 Cloudflare 账号或付费服务。
